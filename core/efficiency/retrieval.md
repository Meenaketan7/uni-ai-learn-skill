# Focused retrieval
Locate a file, symbol or source before opening content. Start with at most 160
lines or 8 KiB per targeted read; expand when the question requires more.
Cache resource identity, revision/hash, scope and retrieval time; invalidate
after change. A remembered line number is navigation, not source identity.
Keep stable instructions before changing task data where the host permits.
Return claims with path/symbol/revision or URL and retrieval date evidence.
Retain counterevidence, uncertainty, failed attempts and the next decision.
Aim for handoffs of about 600 tokens without dropping mandatory facts. Reopen the narrow
source needed for the receiver's decision. Preserve raw output when a filter
removes a useful failure. A graph and a compressed summary do not replace it.
A model recommendation is not a confirmed switch. Use only qualified available
bindings; include retries, handoffs, compaction and unknown costs in comparisons.
Do not cap correctness or useful explanations to meet a token target.
