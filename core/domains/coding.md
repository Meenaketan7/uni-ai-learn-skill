# Coding evidence
Use behavior, invariants, state transitions and rejected operations as evidence.
Ask for a failing example and predicted state before revealing execution.
Questions: what must remain true; which operation can fail after mutation;
what boundary case separates the hypotheses; which test checks the contract?
Assess observable correctness, rejection safety, failures and maintainability.
The learner’s explanation should explain the mechanism and transfer to a different failure.
Reuse the shared loop; this pack does not create a separate learning engine.
