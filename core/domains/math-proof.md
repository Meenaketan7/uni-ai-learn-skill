# Proof evidence
State domain, assumptions and conclusion. Ask which inference is justified and
predict a counterexample before evaluating it. Check zero, sign, degeneracy,
quantifiers and hidden division/invertibility assumptions.
Questions: does the example satisfy the premise; what assumption makes this
step valid; can a stronger hypothesis repair the claim; is a case split needed?
Assess validity of each inference and explicit scope, not confidence of prose.
The learner’s explanation should explain the missing condition and a new boundary example.
Reuse the shared loop and the same hint levels.
