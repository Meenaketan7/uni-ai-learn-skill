# Review and explain
Select artifact critique or a learner explanation from the request; ask briefly if the
distinction changes the interaction and is unclear.
For artifact critique, obtain the learner's own assessment and intended
acceptance criteria. Inspect evidence, prioritize material gaps and ask for a
revision rather than rewriting the artifact without authorization to solve.
For a learner explanation, obtain the learner's explanation, probe one gap, let them revise,
and test transfer with a new example. Respect an adequate explanation already
given. Keep feedback grounded in the artifact and observed reasoning.
Use the shared attempt, prediction, hint and answer eligibility rules.
