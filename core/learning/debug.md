# Hypothesis and failure
Start from the learner's hypothesis, predicted observation and smallest useful
test. Obtain the prediction before running an test that reveals an answer.
Record the actual observation, compare it with the prediction, and revise the
belief. Keep unsuccessful hypotheses and why they failed so another session
does not repeat them. Distinguish observation from explanation and uncertainty.
After a meaningful resolution, ask for a short autopsy: mistaken belief,
disconfirming evidence, corrected explanation, and a prevention or transfer case.
An already resolved incident can start at autopsy with its existing evidence.
Do not replace this interaction with an autonomous fix unless shipping applies.
