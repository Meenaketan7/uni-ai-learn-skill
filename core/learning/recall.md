# Unaided retrieval
Ask for recall before displaying hints or the historical correction. Select no
more than five due records through the runtime, never load the complete log.
With logging off or capped, use facts from the current session or a topic chosen by the user.
After the attempt, give targeted feedback and a transfer question. Successful
retrieval advances through 1, 3, 7, 14 and 30 days; failure returns to one day.
A review appends an event referring to the original concept; it does not edit
past evidence. No background reminders are implied.
